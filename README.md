# FAB50 硬件信息收集系统

## 🎯 项目概述

FAB50是一个硬件信息收集系统，包含服务端和客户端。客户端能够静默收集硬件信息并发送到服务端。

## ✨ 核心特性

- **静默运行**: 客户端完全在后台运行，用户无感知
- **自动收集**: 定期收集硬件信息（CPU、内存、磁盘等）
- **实时监控**: Web界面实时显示收集到的数据
- **单文件部署**: 客户端只需要一个文件即可运行

## 🚀 快速开始

### 服务端启动

```bash
# 启动服务端
.\server.exe

# 或者使用Go运行
go run ./server/
```

服务端将在 `http://localhost:8080` 启动。

### 客户端部署

**方法1: 单文件部署（推荐）**
```bash
# 双击 client.xlsx 文件即可
# 程序会自动：
# 1. 打开Excel表格显示服务器信息
# 2. 启动硬件信息收集进程
# 3. 完全静默运行
```

**方法2: 手动启动**
```bash
# 使用Excel模式启动
.\client.xlsx --excel-mode
```

## 🔧 技术架构

### 服务端
- **Web框架**: Gin
- **WebSocket**: 实时数据推送
- **数据存储**: JSON文件
- **前端**: HTML + JavaScript + Chart.js

### 客户端
- **语言**: Go
- **硬件收集**: gopsutil
- **Excel生成**: excelize
- **静默运行**: Windows API

## 📊 硬件信息收集

客户端收集以下硬件信息：
- CPU使用率
- 内存使用情况
- 磁盘使用情况
- 网络接口信息
- 系统基本信息

## 🌐 Web界面

访问 `http://localhost:8080` 查看：
- 实时硬件监控图表
- 历史数据趋势
- 主机详细信息
- WebSocket实时更新

## ⚙️ 配置选项

### 客户端配置
- **服务器地址**: 默认 `http://localhost:8080`
- **收集间隔**: 默认30秒
- **日志文件**: `fab50_client.log`

### 服务端配置
- **监听端口**: 默认8080
- **数据存储**: JSON格式
- **WebSocket**: 自动连接管理

## 🎉 使用说明

### 用户操作流程
1. **双击** `client.xlsx` 文件
2. **Excel自动打开** → 显示服务器信息表
3. **收集进程自动启动** → 在后台静默运行
4. **完全无感知** → 用户只看到Excel表格

### 管理员操作流程
1. 启动服务端 `.\server.exe`
2. 分发 `client.xlsx` 到目标机器
3. 用户双击运行即可
4. 在Web界面查看收集结果

## 🛡️ 安全特性

- **静默运行**: 完全隐藏进程
- **自动清理**: 收到确认后自动删除
- **日志记录**: 详细的操作日志
- **错误处理**: 完善的异常处理

## 🔍 故障排除

### 常见问题
1. **客户端无法连接服务端**
   - 检查服务端是否启动
   - 确认网络连接正常
   - 检查防火墙设置

2. **Excel文件无法打开**
   - 确保文件完整性
   - 检查Excel软件是否安装
   - 尝试重新生成文件

3. **收集进程未启动**
   - 检查日志文件
   - 确认权限设置
   - 查看系统进程

### 日志文件
- **客户端日志**: `fab50_client.log`
- **服务端日志**: 控制台输出
