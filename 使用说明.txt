FAB50 使用说明
===============

## 概述
FAB50是一个硬件信息监控系统，现在使用两个文件来实现功能！

## 核心特性
✅ 两个文件分工明确
✅ client.exe - 启动收集进程
✅ client.xlsx - 显示服务器信息表
✅ 收集进程静默运行

## 使用方法

### 1. 编译和构建
```bash
# 运行构建脚本
.\build_xlsx.bat

# 或者手动构建
go build -o client.exe cmd/client/
.\client.exe  # 生成Excel文件
```

### 2. 使用
- **双击 client.xlsx** → 用Excel打开显示服务器信息表
- **双击 client.exe** → 启动硬件信息收集进程
- 收集进程在后台静默运行

## 工作流程
1. 构建 → 生成 client.exe 和 client.xlsx
2. 双击 client.xlsx → 打开Excel表格
3. 双击 client.exe → 启动收集进程
4. 后台运行 → 静默监控
5. 自动清理 → 收到确认后删除

## 文件说明
- **client.exe** - 可执行程序（启动收集进程）
- **client.xlsx** - Excel文件（显示服务器信息表）
- **build_xlsx.bat** - 构建脚本（可选使用）

## 注意事项
- 收集进程完全静默运行
- 所有日志保存在 fab50_client.log
- 收到服务端确认后自动删除自身
- 需要两个文件配合使用

## 技术实现
- 程序检测启动参数
- 如果是 --excel-mode，则只启动收集进程
- 否则生成Excel文件并启动收集进程
- Excel文件使用Excelize库生成标准格式

---
总结：现在您有两个文件，分别用于显示Excel表格和启动收集进程！🎉
